# 上班鼓励器 (Work Cheer)

一个 macOS 桌面悬浮小组件:实时显示在岗状态、工资到账金额、下班倒计时,让每一分钟的努力都"看得见"。

原生 Swift / SwiftUI / AppKit 编写,体积约 1.7 MB,支持 Apple Silicon 与 Intel(Universal),最低 macOS 13。

## 功能

**核心**
- 在岗状态:在岗 / 午休 / 加班 / 未上班 / 休息日,带呼吸状态灯
- 实时到账:按秒累计的工资金额,支持今日 / 本周 / 本月 / 今年切换(点击标签)
- 下班倒计时与已工作时长,环形进度图
- 收入速率:每秒 / 每分钟 / 日薪

**工资计算**
- 日薪 = 月薪 ÷ 每月工作日(默认 21.75),午休不计薪
- 加班费倍数(默认 1.5)
- 法定节假日 / 调休自动识别(holiday-cn),否则按周末规则
- 锁屏 / 睡眠 / 息屏自动暂停计时

**趣味与激励**
- 轮播鼓励语,支持自定义
- 金额等价物("≈ N 杯奶茶")、发薪日倒计时
- 金额里程碑通知
- 多币种显示(实时汇率,每小时刷新)
- 成就卡片:一键生成可分享的 PNG
- 收入趋势图:近 14 天 / 8 周

**桌面体验**
- 悬浮窗,所有桌面可见,可自由拉伸,布局自适应
- 三档信息密度:迷你 / 标准 / 完整
- 菜单栏图标实时显示金额
- 隐私模式:点击金额隐藏(隐藏时仍有跳动动画)
- 透明度、浅色 / 深色 / 跟随系统、主题强调色
- 全局快捷键 `⌃⌥W` 显示 / 隐藏
- 开机自启、下班通知、喝水休息提醒
- 导出今年收入 CSV
- 中文 / English

## 安装

打开 `上班鼓励器-1.2.dmg`,将 App 拖入 Applications。

> 应用为 ad-hoc 签名,未经 Apple 公证。首次打开请 **右键 → 打开**,或在"系统设置 → 隐私与安全性"中点击"仍要打开"。


## 使用提示

- 点击金额:隐藏 / 显示;点击金额上方标签:切换统计周期
- 在设置里填写月薪、上下班与午休时间、发薪日后即可使用
- 历史收入按日薪估算,不保存真实流水
- 通知通过 `osascript` 发送,如未弹出请在系统设置中允许相关通知

## 说明

金额仅为按设定参数的估算,供娱乐和激励之用,不代表实际工资。
