# 上班鼓励器 (Work Cheer)

一个 macOS 桌面悬浮小组件:实时显示在岗状态、工资到账金额、下班倒计时,让每一分钟的努力都"看得见"。

原生 Swift / SwiftUI / AppKit 编写,安装包约 13 MB(含内置宠物),支持 Apple Silicon 与 Intel(Universal),最低 macOS 13。

## 功能

**核心**
- 在岗状态:在岗 / 午休 / 加班 / 未上班 / 休息日 / 休假中,带呼吸状态灯
- 实时到账:按秒累计的工资金额,支持今日 / 本周 / 本月 / 今年切换(点击标签)
- 下班倒计时与已工作时长,环形进度图
- 收入速率:每秒 / 每分钟 / 日薪

**工资计算**
- 日薪 = 月薪 ÷ 每月工作日(默认 21.75),午休不计薪
- 加班费倍数(默认 1.5)
- 法定节假日 / 调休自动识别(holiday-cn),否则按周末规则
- 锁屏 / 睡眠 / 息屏自动暂停计时

**趣味与激励**
- 轮播鼓励语,支持自定义
- 金额等价物("≈ N 杯奶茶")、发薪日倒计时
- 金额里程碑通知
- 多币种显示(实时汇率,每小时刷新)
- 成就卡片:一键生成可分享的 PNG
- 收入趋势图:近 14 天 / 8 周

**桌面体验**
- 悬浮窗,所有桌面可见,可自由拉伸,布局自适应
- 三档信息密度:迷你 / 标准 / 完整
- 菜单栏图标实时显示金额
- 隐私模式:点击金额隐藏(隐藏时仍有跳动动画)
- 透明度、浅色 / 深色 / 跟随系统、主题强调色
- 全局快捷键 `⌃⌥W` 显示 / 隐藏
- 菜单栏自适应:刘海屏空间不足时自动缩成 💰 图标,普通屏显示完整金额
- 关闭窗口后点击 Dock 图标或菜单栏图标即可唤回
- 开机自启、下班通知、喝水休息提醒
- 设置分为 工资 / 目标 / 宠物 / 外观 / 通用 五个标签页,相关项联动启用
- 导出今年收入 CSV
- 中文 / English

**目标与效率**
- 每日收入目标:达成时通知、宠物庆祝,并记录连续达成天数
- 心愿存钱罐:设定心愿和金额,显示进度与还需工作日
- 专注模式(番茄钟):菜单栏或宠物右键开始,默认 25 分钟专注 + 5 分钟休息,宠物陪你工作
- 请假标记:事假(不计薪)与年假/调休(照常计薪),工资与连续天数自动调整
- 周报 / 月报:出勤、请假、工时、加班、日均、专注数和每日柱状图,支持复制文字或保存为分享图(菜单栏、宠物右键或设置里打开)
- 下班前 10 分钟宠物提示倒计时,到点跑出屏幕下班

**桌面宠物**
- 关闭主窗口后,桌面上会出现一只小宠物,在屏幕底部来回跑动,头顶显示当前金额
- 互动:点击挥手并说一句鼓励语;按住拖起、松手落下;右键打开菜单
- 状态联动:上班时走动 / 工作,加班时一脸疲惫,到点下班时欢呼跳跃,午休时睡觉
- 走动时会朝移动方向微微侧身,更有立体感
- 内置 6 个宠物形象(默认 The Real Tronald Dump),右键 → 切换宠物 可更换
- 支持导入 [Codex 宠物](https://codex-pets.net/) 格式(含 `pet.json` 与 spritesheet 的文件夹或 zip),右键 → 切换宠物 → 导入宠物…
- 大小可选小 / 中 / 大,可在设置中关闭宠物

## 安装

打开 `上班鼓励器-1.8.2.dmg`,将 App 拖入 Applications。

应用为 ad-hoc 签名,未经 Apple 公证。首次打开请 **右键 → 打开**,或在"系统设置 → 隐私与安全性"中点击"仍要打开"。


## 使用提示

- 宠物素材 `BuiltinPet/` 会随应用打包;导入的宠物保存在 `~/Library/Application Support/WorkCheer/Pets`
- 点击金额:隐藏 / 显示;点击金额上方标签:切换统计周期
- 菜单栏图标菜单可一键开始 / 结束专注、标记今天请假、打开周报
- 宠物右键菜单可切换形象、导入宠物、调整大小、开始专注
- 在设置里填写月薪、上下班与午休时间、发薪日后即可使用
- 应用会每天记录真实在岗时长、加班、收入和专注数,用于周报 / 月报;没运行过的日子按日薪估算(报告里以浅色柱标出)
- 通知通过 `osascript` 发送,如未弹出请在系统设置中允许相关通知

## 说明

金额仅为按设定参数的估算,供娱乐和激励之用,不代表实际工资。
